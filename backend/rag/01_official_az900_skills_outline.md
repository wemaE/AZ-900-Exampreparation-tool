# AZ-900 Official Skills Outline — Scope Map

**Source type:** Official public Microsoft Learn study guide  
**Source URL:** https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900  
**Version checked:** Skills measured as of 20 July 2026  
**Authority:** Primary source  
**Note:** This is a topic map, not a complete course or guarantee of exam content. Check the live page before relying on percentages or objectives.

## Skills at a glance

- Describe cloud concepts: **25–30%**
- Describe Azure architecture and services: **35–40%**
- Describe Azure management and governance: **30–35%**

## 1. Describe cloud concepts (25–30%)

### Cloud computing
- Define cloud computing.
- Explain the shared responsibility model.
- Define public, private, and hybrid cloud models and identify use cases.
- Explain the consumption-based model and compare cloud pricing models.
- Describe serverless computing.

### Benefits of cloud services
- High availability and scalability.
- Reliability and predictability.
- Security and governance.
- Manageability.

### Cloud service types
- Infrastructure as a Service (IaaS).
- Platform as a Service (PaaS).
- Software as a Service (SaaS).
- Appropriate use cases for IaaS, PaaS, and SaaS.

## 2. Describe Azure architecture and services (35–40%)

### Core architecture
- Azure regions, region pairs, sovereign regions, availability zones, and datacenters.
- Azure resources and resource groups.
- Subscriptions and management groups.
- Hierarchy and relationships among management groups, subscriptions, and resource groups.

### Compute and networking
- Containers, virtual machines, and functions.
- Azure Virtual Machines, Virtual Machine Scale Sets, availability sets, and Azure Virtual Desktop.
- Resources required for virtual machines.
- Hosting applications using web apps, containers, and virtual machines.
- Virtual networks, subnets, peering, Azure DNS, Azure VPN Gateway, and ExpressRoute.
- Public and private endpoints.

### Storage
- Compare Azure Storage services.
- Storage access tiers and redundancy options.
- Storage account options and storage types.
- File movement options, including AzCopy, Azure Storage Explorer, and Azure File Sync.
- Migration options, including Azure Migrate and Azure Data Box.

### Identity, access, and security
- Microsoft Entra ID and Microsoft Entra Domain Services.
- Single sign-on (SSO), multifactor authentication (MFA), and passwordless authentication.
- External identities.
- Microsoft Entra Conditional Access.
- Azure role-based access control (RBAC).
- Zero Trust.
- Defense in depth.
- Microsoft Defender for Cloud.

## 3. Describe Azure management and governance (30–35%)

### Cost management
- Factors affecting Azure costs.
- Azure Pricing Calculator.
- Azure cost-management capabilities.
- Tags and their purpose.

### Governance and compliance
- Microsoft Purview in Azure.
- Azure Policy.
- Resource locks.

### Managing and deploying resources
- Azure portal.
- Azure Cloud Shell, Azure CLI, and Azure PowerShell.
- Azure Arc.
- Infrastructure as code (IaC).
- Azure Resource Manager (ARM) and ARM templates.

### Monitoring
- Azure Advisor.
- Azure Service Health.
- Azure Monitor, including Log Analytics, Azure Monitor alerts, and Application Insights.
